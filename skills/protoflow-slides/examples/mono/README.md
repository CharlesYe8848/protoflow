# 样例：黑白极简风（mono）

**性格**：干净、现代、亲和。黑白灰打底，一个强调色做焦点；粗体大字、大数字；圆角浅灰面板、圆角图标底；装饰只有封面、
结束页角上的强调色方块和引言的大引号。

**适合**：产品方案、需求评审、周报月报、对内汇报——内容以"数据 + 结论 + 方案"为主、要看得轻松的场合。

## 用法

这是一份普通的样例，不是模板：可以整套拿来用，也可以只抄一部分，或者只看看思路。

- 整套用：把 `design/` 下的文件拷进幻灯片的 `decks/<deckId>/design/`（先删掉起步的 `design.css`），页面按
  `../LAYOUTS.md` 的骨架写。`sample.html` 是一页封面示例。
- 换配色：用 `palettes/` 里的一个替换 `design/theme.css`——`blue` 蓝（默认，商务）、`orange` 橙（活动、增长）、
  `green` 绿（环保、健康）、`violet` 紫（创意、设计）、`ink` 墨（纯黑白，正式）。也可以直接改 `theme.css` 里的颜色。
- 拷进去以后就是这份幻灯片自己的文件，缺什么版式、想改什么样子直接改。

| 文件 | 内容 |
|---|---|
| `design/pf-kit.css` `pf-kit.js` | 可选工具库（图标、图表、数字滚动、动效），见 `../../references/kit.md` |
| `design/layouts.css` `layouts.js` | 商务版式的骨架（跟 swiss 同一套） |
| `design/mono.css` | 这套的皮肤：字重、圆角、装饰 |
| `design/theme.css` | 配色 |
