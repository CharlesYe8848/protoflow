# 样例：瑞士风（swiss）

**性格**：理性、克制、有冲击力。国际主义排版的思路：直角、网格、强对比；超大字用细体、标题中粗、标签用大写小字；
不用圆角、阴影、渐变；卡片不填底色，只在顶上压一道粗线；一个高饱和强调色做焦点，封面一个压出画面的大圆，章节页
整页强调色。

**适合**：方法论、产品发布、数据汇报、对外分享——想要"有设计感、一眼记住"的场合。字少、结构清楚时效果最好。

## 用法

这是一份普通的样例，不是模板：可以整套拿来用，也可以只抄一部分，或者只看看思路。

- 整套用：把 `design/` 下的文件拷进幻灯片的 `decks/<deckId>/design/`（先删掉起步的 `design.css`），页面按
  `../LAYOUTS.md` 的骨架写（跟 mono 同一套版式，两者之间换不用改页面）。`sample.html` 是一页封面示例。
- 换配色：用 `palettes/` 里的一个替换 `design/theme.css`——`klein` 克莱因蓝（默认）、`red` 瑞士红、`orange` 信号橙、
  `ink` 墨黑（纯黑白）。也可以直接改 `theme.css` 里的颜色。
- 拷进去以后就是这份幻灯片自己的文件，缺什么版式、想改什么样子直接改。

| 文件 | 内容 |
|---|---|
| `design/pf-kit.css` `pf-kit.js` | 可选工具库（图标、图表、数字滚动、动效），见 `../../references/kit.md` |
| `design/layouts.css` `layouts.js` | 商务版式的骨架（跟 mono 同一套） |
| `design/swiss.css` | 这套的皮肤：细体大字、直角、顶线面板 |
| `design/theme.css` | 配色 |
