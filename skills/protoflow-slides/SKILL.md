# 做幻灯片

幻灯片产品（`deck`）是个壳子：放映、版本、嵌入、导出。**每页长什么样由你决定**——按项目背景、素材和这一页要说的事来设计，
版式、配色、字体、动画、交互都不受限制，只要符合文件格式。

开始前跑 `protoflow plugins`，确认 `deck` 产品已启用。

## 要读的

| 什么时候 | 读什么 |
|---|---|
| 动手写页之前 | `get_guide({topic:"deck-writing"})`：文件格式（每页一个 `<section>`、`design/` 共用样式、页内样式脚本管住范围、翻页事件、素材、嵌入、放映配置）。这是唯一的硬约定 |
| 定设计方向、检查效果时 | `references/principles.md`：不管什么风格都成立的设计原则 |
| 想用现成的图标、图表、数字滚动、进场动效 | `references/kit.md`：可选工具库 `lib/pf-kit.*`，拷进 `design/` 就能用 |
| 有视频、背景音乐、旁白，或者要当视频放 | `references/media.md`：声音的目标（响度、比例、长度）和 `scripts/media.mjs`（准备素材、体检） |
| 汇报、评审这类场合想要现成的样子 | `examples/`：`mono` 黑白极简、`swiss` 瑞士风两个视觉样例，整套拷进 `design/` 用、抄一部分、或只看思路都行；仓库 `examples/annual-review/` 另有十页年终汇报完整场景示例 |

## 做法

按任务大小取舍：三页的小汇报不用走完每一步，大型发布可以多轮打磨。

1. **弄清要什么**：给谁看、什么场合、讲多久（大约一分钟一页）、有哪些素材（项目里的表格、绘图、原型，文档、数据、
   照片、视频）。用户已经给够了就直接往下做，缺关键信息再问，一次问完。
2. **排叙事**：先定整份的故事线，再定每页让人记住的一件事，以及用什么形式表现它（图表、大数字、照片、流程、一句话……）。
   篇幅大的先把逐页计划给用户看一眼。
3. **定方向**：按场合和内容定整体的样子——配色从品牌、素材（比如照片的主色）、场合里来。合适就用样例或以前哪份稿子的
   `design/`（直接拷），不合适就从零设计。
4. **写**：`create_deck({ projectId, deckId, title })` 建幻灯片，页写进 `decks/<deckId>/slides/`，几页都要用的样式脚本放
   `design/`。
   - 项目里已有的表格、绘图用 `<pf-embed ref="…">` 嵌进来，不要手抄数字。
   - 画布里的原型要截图时用流程 skill `protoflow-product-dev` 的截图脚本（capture），截图旁的出处文件
     `build_deck` 时会记进引用，原型改了幻灯片会提示过期。
   - 自动翻页、背景音乐、旁白、视频按 `deck-writing` 写 `playback.json`，不要在页里写计时器或音频自动播放。
     音视频素材先用 `scripts/media.mjs prepare` 处理（格式、响度、封面），见 `references/media.md`。
5. **确认效果**：写 HTML 时看不到渲染结果，定版前要确认每页实际的样子符合原则。可用的：
   - `node <本 skill 目录>/scripts/check.mjs --projectId <项目> --deckId <幻灯片> [--shots <截图目录>]`：在无头浏览器里逐页
     渲染草稿（不用先定版）。error 是硬伤，必须改（超出画布、文字被裁、资源加载失败、脚本报错、依赖外部地址）；warn 带着位置，
     你判断是不是有意的（元素重叠、字小于 24px、页里的样式改到了别的页、背景音乐不够长）。`--shots` 出每页截图；
     输出里的 `timeline` 是自动放映时每页从第几秒开始、全片多长，`unusedAssets` 是 assets/ 里没被引用的文件。
   - 有声音时：`node <本 skill 目录>/scripts/media.mjs audit --projectId <项目> --deckId <幻灯片>`，查各段响度、破音、冷场、
     背景音乐和原声的比例。
   - 定版后的阅读页。
6. **定版、交付**：`build_deck({ projectId, deckId, note:"这次改了什么" })`，每改一轮定一个版本，旧的留作历史（`?v=<n>`）。
   第一次把返回的 url 给用户；阅读页开着时定了新版本会自动刷新，之后每轮说"已定 v<n>"就行，不用再给链接或再打开。
   有声音的幻灯片提醒用户点一次「播放」。要文件时 `export_deck`：`pdf`（发邮件、打印）、`mp4`（要视频、相册视频，按放映配置录，要本机有 ffmpeg）、`html`（带自动翻页和音频时）、`zip`（源文件）。

## 复用

用户说"跟上次那份一个风格"，把那份幻灯片的 `design/` 拷过来，再按这次的内容改。
