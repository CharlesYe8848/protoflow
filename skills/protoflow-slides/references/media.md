# 音视频

幻灯片当视频放（自动翻页、背景音乐、页里的视频原声）时，声音比画面更容易出问题：几段视频忽大忽小、背景音乐一起一落、
某页突然没声、放到最后音乐没了。下面是目标，`scripts/media.mjs` 帮你做到、帮你查。要本机有 ffmpeg。

## 目标

| 什么 | 目标 | 为什么 |
|---|---|---|
| 视频格式 | H.264 画面 + AAC 声音的 `.mp4`，配 `poster` | 手机拍的 HEVC（`.MOV`）浏览器放不稳；没有封面图，缩略图和 PDF 里是空白 |
| 视频原声 | 各段统一在 -18 LUFS 左右，真峰值不超过 -1.5 dBTP | 不统一的话一段轻一段响，还可能在音箱上破音 |
| 只有底噪的视频 | 加 `muted`（或去掉声音） | 没静音的视频一播，背景音乐就被压下去；原声又没内容，就成了冷场 |
| 背景音乐 | 照片页上比视频原声低 5–8 LU；视频说话时再压低 10 LU 左右 | 太响盖过说话声；避让压得太深，照片页、视频页交替时音乐会一起一落 |
| 音乐长度 | 盖住整场自动放映，最后一页留够音乐再淡出 | 最后一页往往是情绪最高的地方，音乐先没了很可惜 |

背景音乐的实际响度 = 文件本身的响度 + 20·log10(`volume`)。比如文件 -14 LUFS、`volume: 0.3`，实际约 -24.5 LUFS。

## 做法

- **拿到素材先准备**：`node <本 skill 目录>/scripts/media.mjs prepare <视频或音频…> --out decks/<deckId>/assets`
  转成浏览器放得稳的格式、拉平响度、给视频截封面（`<名>-poster.jpg`）。原文件不动。只有底噪的视频加 `--no-audio`。
  背景音乐、旁白也可以用它拉平，再用 `playback.json` 里的 `volume` 调比例。
- **放进页面以后体检**：`node <本 skill 目录>/scripts/media.mjs audit --projectId <项目> --deckId <幻灯片>`
  列出每段的格式、时长、响度、峰值和背景音乐的实际响度，标出偏离太多、会破音、只有底噪却没静音、音乐盖过原声的。
- **音乐够不够长**：`check.mjs` 的输出里有 `timeline`，按 `playback.json` 算出每页从第几秒开始、全片多长；音乐在最后一页之前
  放完会报 `BGM_SHORT`。不够长就换一首、续接一段（接在原曲同一位置上最自然），或者 `loop: true`。算出来的时间不含视频加载的
  延迟，实际会晚一点（每页零点一秒左右）。
- 拉平之后留下的旧文件没人引用，`check.mjs` 会报 `UNUSED_ASSET`；确定不要了可以删，省得每次定版都带着。
