# ProtoFlow v0.2.0 — 绘图、表格与幻灯片

这一版把 ProtoFlow 从原型与文档工具扩展为一套可组合的产品交付工作流。新增独立的绘图、结构化表格与幻灯片产品；画布和文档也完成版本、导出与架构升级。五类交付物可以各自创建和定版，也可以通过固定版本引用组合在一起。

## 新增能力

- **绘图**：用 Markdown / Mermaid 创建多页脑图、流程图、时序图、状态图、实体关系图和类图，自动排版；支持节点选择、框选、右键标注、版本切换，以及单页 HTML 和源文件包导出。
- **结构化表格**：用 JSON 维护多工作表、样式、合并单元格和图片，支持版本预览、选区标注以及 Excel（`.xlsx`）导出。
- **幻灯片**：每页使用 HTML 自由排版，支持共享设计与素材、表格和绘图嵌入、元素标注、版本管理，以及 PDF、MP4、单页 HTML 和源文件包导出。可配置自动翻页、背景音乐、逐页旁白和视频。

## 画布与文档升级

- **画布版本化与多画布**：同一项目可分别维护管理端、移动端或 A/B 方案画布；画布支持不可变版本、历史切换、内容寻址存储、实时预览和更可靠的元素定位。
- **文档增强**：文档可嵌入已定版的表格和绘图，新增 Word（`.docx`）导出，并保留单页 HTML、Markdown 和目录树导出。
- **统一交互**：五类交付物共享项目导航、版本切换、导出入口、元素选择与标注体验；本地页面支持实时刷新。

## 平台与工作流升级

- **统一版本与引用**：画布、文档、表格、绘图和幻灯片均采用“草稿 + 不可变版本 + head”；跨产品引用固定到具体版本，上游更新后会提示过期。
- **内容寻址版本库**：相同文件跨版本和跨交付物只存一份，同时保持历史版本不可变。
- **可扩展产品架构**：核心能力拆分为产品插件，提供稳定 SDK、外部插件加载、按配置启停和依赖边界检查。
- **CLI + skill 工作方式**：移除原 MCP 入口，统一使用 `protoflow` CLI；工具从 22 个扩展到 30 个。仓库包含入口 skill `protoflow`，以及产品研发流程 `protoflow-product-dev` 和幻灯片创作流程 `protoflow-slides`。
- **流程与产品解耦**：PRD、上线公告、截图和发布前检查移入产品研发 skill；框架只负责产品、版本、引用和健康状态。

## 安装与升级

需要 Node.js >= 22.12.0。

```bash
git clone https://github.com/CharlesYe8848/protoflow.git
cd protoflow
npm ci
npm run demo
```

已有本地仓库可运行 `git pull` 和 `npm ci` 更新。v0.1.0 的项目格式需要迁移：先运行

```bash
node bin/protoflow-migrate.mjs <工作区目录>
node bin/protoflow-migrate.mjs <工作区目录> --apply
```

第一条只预演，第二条会在 `<工作区目录>/.protoflow-backup/` 备份后执行迁移。使用软链接安装 skill 或 CLI 的用户无需重新链接；复制安装的 skill 需要重新复制本版的三个 skill。原 MCP 配置可以移除。
