# ProtoFlow v0.2.1 — 年终汇报完整示例

这是 v0.2 系列的第一个补丁版本，补上了一份可以直接运行、继续修改的完整幻灯片场景。

## 新增

- **十页年终汇报**：按“年度结论 → 核心数据 → 增长原因 → 经验复盘 → 下一年计划”组织，包含大数字、柱状图、图标网格、对比、卡片和时间线等版式。
- **可持续编辑**：示例本身是已经定版的 ProtoFlow 项目，保留草稿、不可变版本和内容寻址对象；可以直接交给 agent 替换成真实团队数据并保存新版本。
- **一键体验**：`npm run demo` 现在同时输出结账原型、PRD、上线公告和 `annualReview` 幻灯片链接。
- **文档导航**：README、示例说明和 `protoflow-slides` skill 均增加年终汇报入口。

示例里的公司、人物与经营数据均为虚构，仅用于演示。

## 安装与升级

需要 Node.js >= 22.12.0。

```bash
git pull
npm ci
npm run demo
```

使用软链接安装 skill 的用户无需重新安装；复制安装的用户需要重新复制三个 skill。
